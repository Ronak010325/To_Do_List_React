A ToDo List Application which allows you to manage your day to day Activities.
To see the Output follow this Step:
1.Copy the URL of this repo
2.Go to your Code editior open CMD
3.Cd over to a new folder
4.Set Remote to the URL you copied
5.Run Command: npm install 
6.After that: npm run dev
7.Open "http://localhost:5173/" in your browser.
