A ToDo List Application which allows you to manage your day to day Activities.<br>
To see the Output follow this Step:<br>
1.Copy the URL of this repo<br>
2.Go to your Code editior open CMD<br>
3.Cd over to a new folder<br>
4.Set Remote to the URL you copied<br>
5.Run Command: npm install<br>
6.After that: npm run dev<br>
7.Open "http://localhost:5173/" in your browser.<br>
